## Дүгнэлт

Antisocial аялал хамгийн олон согог (BUG-04-11, 19, 24, 25) олсон бол Saboteur хамгийн ноцтой согогуудыг олсон: `null` body эсвэл объект утгатай ганц хүсэлт серверийг унагаж бүх өгөгдлийг устгадаг (BUG-16, 21), 100 мянга орчим номтой үед статистик серверийг унагадаг (BUG-23). Supermodel харагдах байдлын 5 согог (BUG-15, 17-20), FedEx тоолуурын BUG-12 ба устгах үйлдлийн мессеж, хуучирсан tab-ийн асуудлыг, Couch Potato хоосон оролт ба давтан даралтын BUG-01-03-ыг олсон. Charter-аас гадуур санамсаргүй олдсон нь хайлт гарчиг, зохиолчийг залгаж хайдаг BUG-11, BUG-16-гийн дараа «сервер унасан үед UI яах вэ» гэсэн санаанаас гарсан BUG-22, үл харагдах тэмдэгтийн BUG-24 ба хайлтын race BUG-25 байв. Шалгагдаагүй үлдсэн нь Firefox, Safari дээрх зан төлөв, бодит screen reader-ээр ашиглах, CSRF ба аюулгүй байдлын header-ийн нөлөө, удаан ажиллах үеийн санах ой тул эдгээр дараагийн session-ий charter болно. Лаб 1-ийн Playwright тест текст, мөрийн тоо, статус кодыг assertion-оор шалгадаг тул BUG-01, 03, 04, 06, 09, 10, 12, 15, `request` API-аар 13, 14, 16, 21-ийг тест бичсэн тохиолдолд барина, BUG-17-ийн латин x нь `getByText('Нэмэх')` элемент олохгүй унах замаар санамсаргүй баригдана. Харин ногоон Устгах товч (BUG-18), «1,971» бичлэг (BUG-19), хүснэгт хэтрэх ба утсанд таслагдах (BUG-07, 20), `&amp;` гэж харагдах (BUG-08), «Clean Code» мэт харагддаг хуурмаг нэр (BUG-24) нь DOM-д текст нь байгаа тул автомат тест тэнцэнэ, зөвхөн хүний нүд анзаарна. Тиймээс автомат тест спецификацийн тодорхой дүрмийг давтан шалгахад, exploratory тест хэн ч тест бичиж амжаагүй харагдах байдал, хэт оролт, уналтыг олоход тохиромжтой.
