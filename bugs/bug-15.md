# BUG-15: «Хуучин хувилбар» линк (/old) 500 Internal Server Error буцаана

Орчин:  Уншлагын жагсаалт v2.0, Google Chrome 157.0.8103.79 ба curl 8.7.1, macOS 26.5.2, 2026-11-23  
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. Браузераар http://localhost:3000 нээ.
2. Хуудасны доод талын «Хуучин хувилбар» линк дээр дар.
3. Терминалд: `curl -i localhost:3000/old`

Хүлээгдэж байсан: «... бүх хуудас, линк ажиллана.»  
Бодит үр дүн:     Алхам 2-т цагаан хуудсанд «Internal Server Error», буцах линкгүй. Алхам 3-т `HTTP/1.1 500 Internal Server Error`. Сервер унахгүй.

Ноцтой байдал: Minor. Үндсэн ажиллагаанд нөлөөгүй ч нүүр хуудаснаас шууд хандах линк эвдэрхий.
